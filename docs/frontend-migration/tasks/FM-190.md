## Outcome

`SearchHistoryPage.tsx` (1025), `DownloadHistoryPage.tsx` (540) and `NotificationHistoryPage.tsx` (423) each restate the
same page plumbing: the `useHistoryFilterCriteria` destructure, the page/size/sort read out of `historySearchParams`, the
`useQuery` whose key is the derived filter *model* with `placeholderData: keepPreviousData` and a threaded `signal`, the
`updateSort` and `changePageSize` handlers, and the header / refreshing-status / malformed-count / empty-state / scroller /
pager frame around the table. FM-110 unified only the four provably identical shapes; this task takes the remaining
plumbing — a `useHistoryPage` hook plus a frame component in `features/stats/history/` — leaving each page as its
dimensions, its columns and its rows. Behaviour-preserving: no rendered output, `data-testid`, URL shape or request
changes. Backlog item 21; the three routes move together because the hook's shape is only readable off all three.
